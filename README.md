# Cobble-migos

A Fabric 1.21.1 Cobblemon-focused modpack.

## Basics

- Pack format: `packwiz`
- Minecraft: `1.21.1`
- Fabric Loader: `0.18.4`
- This pack mainly uses mods sourced from Modrinth.

## Mods in this pack that are Modrinth-only

- Animatica
- BetterGrassify
- Continuity
- Debugify
- Dynamic FPS
- Enhanced Block Entities
- FastQuit
- ImmediatelyFast
- ModernFix
- MoreCulling
- Platform
- Remove Reloading Screen
- Tectonic
- Terralith
- Vanilla Backport
- Zoomify
